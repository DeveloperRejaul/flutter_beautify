# Layout Components

Container and organization elements for building app structure.

## Available Components

- **Card** - Content container with shadow
- **BottomSheet** - Sliding panel from bottom
- **Sidebar** - Navigation sidebar menu
- **Breadcrumb** - Navigation hierarchy
- **Accordion** - Expandable sections

---

## Use Cases

| Component | Best For |
|-----------|----------|
| Card | Displaying grouped content |
| BottomSheet | Mobile menus and modals |
| Sidebar | App navigation |
| Breadcrumb | Site hierarchy |
| Accordion | FAQs and expandable lists |
