# Progress & Loading

Progress indication and loading states.

## Available Components

- **LinearProgress** - Linear progress bar
- **CircularProgress** - Circular progress indicator
- **Toast** - Temporary notifications
- **CircularLoader** - Animated loading spinner

---

## When to Use

| Component | Use Case |
|-----------|----------|
| LinearProgress | File uploads, downloads |
| CircularProgress | Percentage-based tasks |
| Toast | Quick notifications |
| CircularLoader | Indefinite loading |
